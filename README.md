# 🏛️ SymbolicPolyLab v1.0.0

### Интерактивный научно-образовательный комплекс символьных вычислений, криптографии и гибридного логического ИИ

[![Python: 3.8+](https://shields.io)](https://python.org)
[![Z3: Inside](https://shields.io)](https://github.com)
[![Tsetlin: Active](https://shields.io)](#)

**SymbolicPolyLab** — это продвинутая вычислительная экосистема и думающий логический движок, разработанный как отечественная альтернатива тяжеловесным пакетам инженерных расчетов (PTC Mathcad, MATLAB). Комплекс объединяет классическую высшую алгебру, теорию полей, современную криптографию и методы формальной верификации предикатов в едином интерактивном интерфейсе.

В отличие от традиционных "калькуляторов", которые просто вычисляют формулы по точкам, **SymbolicPolyLab** оперирует смыслами и образами. Он самостоятельно выводит математические законы, строит пошаговые леммы доказательств, локализует ошибки и ищет уязвимости в логических системах.

## 🚀 Ключевые возможности и Математические движки

### 🏫 1. Базовый школьный модуль (8–11 классы)
* **Деление многочленов уголком:** Пошаговая визуализация деления полиномов столбиком с автоматическим разбором знаков и защитой от типичных ошибок учащихся.
* **Синтетическое деление (Схема Горнера):** Оптимизированный матричный расчет коэффициентов линейных делителей, экономящий 80% времени.
* **Режим "Детектив" (Найди ошибку):** Интеллектуальный тренажер, умышленно вносящий мутации в знаки (+/-) для развития математической зоркости.
* **Генератор контрольных работ:** Мгновенное создание распечатываемых бланков из 5 уникальных задач нарастающей сложности с ключами ответов для преподавателя.

### 🎓 2. Университетский модуль высшей алгебры
* **Полиномиальный алгоритм Евклида:** Пошаговое нахождение Наибольшего Общего Делителя (НОД) в кольцах многочленов \(K[x]\) с автоматической нормировкой.
* **Теорема об остатках (КТО):** Гаусс-Лагранж деконструкция и восстановление многочленов по произвольной системе сравнений по модулю.
* **Система функций Штурма:** Символьное построение цепочек Штурма и локализация точного числа вещественных корней на интервалах.
* **Анализ комплексных корней:** Автоматическое сканирование полного спектра корней на комплексной плоскости \(\mathbb{C}\) с визуализацией сопряженных пар.

### 🔐 3. НИИ Модуль криптографии и дискретных полей
* **Арифметика полей Галуа GF(2):** Пошаговое деление двоичных полиномов через аппаратные битовые маски и побитовые XOR-операции (база для кодов CRC-32, AES и Рида-Соломона).
* **Факторизация Безу-Берелекэмпа:** Разложение полиномов высших степеней на неприводимые множители над полями \(\mathbb{R}\) и \(\mathbb{C}\).

### ⚡ 4. Гибридный ИИ-движок формального вывода (Z3 & Цетлин Core)
* **Каскадная верификация предикатов:** Автоматическое доказательство теорем (методом от противного, прямой импликацией или математической индукцией) на базе C++ ядра **Z3 SMT Solver**.
* **Символьно-Смысловой ИИ Илюхина-Цетлина:** Дополнительный контур интуитивного логического вывода. При таймаутах или ограничениях неполноты Гёделя, система запускает игру **Марковских автоматов Цетлина**, которые обучаются без нейросетей и градиентного спуска непосредственно в дискретной среде, подбирая устойчивые математические леммы.
* **Топологический препроцессор упругой линии:** Динамическое изменение памяти автоматов на основе геометрии изгиба стержня Илюхина, защищающее систему от бесконечного логического зацикливания.
* **Интегрированная среда кода:** Полноценная консоль выполнения русских макрокоманд ("ввод", "штурм", "посчитать") и полноценных скриптов в стиле Jupyter Notebook (выполнение ячеек через `Ctrl+Enter`).

## 🛠️ Установка и Запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com
cd SymbolicPolyLab
```

2. Установите необходимые зависимости ядра:
```bash
pip install z3-solver sympy numpy matplotlib networkx reportlab g4f
```

3. Запустите комплекс:
```bash
python main.py
```
